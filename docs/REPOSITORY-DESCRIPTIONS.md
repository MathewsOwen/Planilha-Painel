## Descrição curta (recomendada — GitHub About)

**Português**

```
Transforme qualquer planilha CSV em um painel executivo: KPIs, gráficos interativos e filtros — um HTML offline que abre em qualquer navegador, sem instalar nada. Inclui apenas dados fictícios; seus dados ficam na sua máquina.
```

**English**

```
CSV/Excel analytics dashboard: build a single offline HTML file with KPIs, charts and filters, or run Streamlit locally. Sample data only in the repo — keep real spreadsheets on your machine.
```

## Descrição um pouco mais longa (opcional — release ou README do About)

**Português**

```
Transforme exportações de planilha em um painel interativo. Um comando gera dashboard.html para abrir em qualquer navegador, sem instalar Python no PC de uso. Suporta cabeçalhos variados, detecção automática de colunas e atualização por arrastar um CSV novo.
```

**English**

```
Turn spreadsheet exports into an interactive dashboard. One build step produces dashboard.html for any browser—no Python required on the viewer machine. Flexible headers, automatic column detection, and drag-and-drop CSV refresh.
```
