# Dados da planilha

| Arquivo | Uso |
|---------|-----|
| `planilha.exemplo.csv` | Dados **fictícios** versionados no Git (amostra) |
| `planilha.csv` | Sua planilha **real** (crie localmente; não commitar) |

```bat
copy planilha.exemplo.csv planilha.csv
```

Edite `planilha.csv` no Excel. Salve como CSV UTF-8 com separador `;`.

Cabeçalho recomendado: `CARGO ATUAL`, `INÍCIO DO AFASTAMENTO`, `QUANTIDADE DE DIAS DE AFASTAMENTOS`, etc.
